# Ellastic

**Experimental Layered Logic for Audio, Signals, Transformation, Imaging & Corruption**

Ellastic is experimental **databending and datamoshing software** for manipulating audio, images, video, and other digital media.

It provides tools for:

* Databending
* Datamoshing
* Signal manipulation
* Image transformation
* Audio manipulation
* Digital corruption
* Layered transformations

Ellastic treats media as data that can be modified, transformed, and corrupted to create unexpected results.

> **Break or Modify the data and see what happens.**

---
>[!IMPORTANT]
> Ellastic is experimental and still in development.
> Expect broken files. That's sort of the point.
